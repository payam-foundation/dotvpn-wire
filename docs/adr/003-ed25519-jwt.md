# ADR-003: Ed25519 JWT with offline verification

Status: accepted

## Context

Nodes verify tokens with a public key only.

## Decision

A control outage must not kill active users, and a stolen node must not be able to mint tokens. Tokens live 15 minutes with `exp`/`nbf` and a key id for rotation; revocation is short life plus a pushed deny-list. Clients anchor their clock to control responses to survive skew.

## Rejected

Opaque tokens checked against control per connection: control becomes a single point of failure on the hot path.
